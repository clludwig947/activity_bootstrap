Viewport

The viewport is the visible area of a webpage on a device’s screen. It changes with the size of the device and is controlled with the meta viewport tag.

Flexbox

The flex layout allows responsive elements within a container to be automatically arranged depending on viewport size.

Grid

A grid layout is a system of rows and columns that helps structure content on a webpage, making it easier to create organized and responsive designs.
